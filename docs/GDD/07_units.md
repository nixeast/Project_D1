# 07. 유닛

## 1. 유닛 파라미터

| 파라미터 | 이름 | 비고 |
|---|---|---|
| ATK | 공격력 | 데미지 계산에 사용 ([06. 전투 § 전투 공식](06_battle.md#2-전투-공식)) |
| HIT | 명중치 | 명중 판정에 사용 |
| DEF | 방어력 | 데미지 계산에 사용 |
| EVA | 회피력 | 명중 판정에 사용 |
| MOV | 이동능력 | 이동 가능 타일 수 |
| HP | 체력 | 0이 되면 사망 |
| SP | 정신력 | 액티브 스킬 사용 비용 ([08. 특성·스킬](08_traits_skills.md#1-스킬-파라미터)) |
| 공포 | 공포 수치 (0~100) | 100에 이르면 1턴 패닉. [§1.2](#12-공포) |

### 1.1 AP와 MOV

이전 문서의 AP(행동력)는 MOV와 같은 개념으로 정리했습니다. 게임 데이터는 `stat_MOV` 열 하나로 정리했습니다(이전 `stat_AP` 값 유지, `stat_mov` 열 삭제). 탐사 이벤트의 '행동력 소모'는 전투의 MOV와 무관하며 보급품 소모로 처리합니다.

### 1.2 공포

유닛마다 **공포 수치(0~100)** 를 가집니다. 0에서 시작하며, 100에 이르면 패닉 상태가 됩니다. 100 미만에서는 불이익이 없습니다.

| 항목 | 내용 |
|---|---|
| 범위 | 0 ~ 100 |
| 증가 요인 | 탐사 이벤트의 공포·사기 저하 선택지, 공포를 유발하는 적의 특성·스킬(영혼의 갈고리 클랜 등) |
| 감소 요인 | 전투 승리, 서포터의 스킬·특성, 탐사 이벤트의 공포 감소·방지 선택지 |
| 캠프 귀환 | 공포는 초기화되지 않고 유지됩니다. |
| 패닉 | 공포가 100이 되면 1턴 동안 플레이어의 명령을 따르지 않고 자동으로 행동합니다. |
| 패닉 종료 | 1턴이 지나면 패닉이 풀리고 공포가 일정량 내려가 다시 명령을 받습니다. |

#### 패닉 행동

패닉이 될 때마다 아래 셋 중 하나가 무작위로 정해집니다.

| 행동 | 확률 | 내용 |
|---|---|---|
| 도망 | 50% | 가장 가까운 적에게서 멀어지는 방향으로 MOV만큼 이동하고, 공격하지 않습니다. |
| 웅크림 | 30% | 이동·공격을 하지 않고, 그 턴 동안 받는 피해가 25% 늘어납니다. |
| 무작위 공격 | 20% | 사거리 안의 아군·적 중 무작위 대상을 공격합니다. |

#### 공포 증감량 (초기값)

| 요인 | 변화량 |
|---|---|
| 적의 공포 유발 특성·스킬 적중 | +25 |
| 탐사 이벤트의 공포·사기 저하 선택지 | +20 |
| 전투 승리 | -20 |
| 탐사 이벤트의 공포 감소·방지 선택지 | -20 |
| 패닉 종료 | -30 |

>
> 현재 서포터 특성·스킬에는 공포를 낮추는 효과가 없습니다. 특성·스킬 대조 작업(A3) 때 함께 추가합니다.

## 3. 드워프

### 3.1 유닛 타입

| 타입 | 컨셉 | 설명 |
|---|---|---|
| 탱커 (Tanker) | 전열의 방패 | 카라두르의 함락 당시 끝까지 무너지지 않고 생존자들의 길을 열었던 이들이 이제 브론즈가드의 단단한 전열이 되었습니다. |
| 근접 딜러 (Melee) | 필사의 칼날 | 방패 뒤에 숨지 않고 적진의 심장을 향해 뛰어드는 카라두르 수복의 선봉장들입니다. |
| 원거리 딜러 (Ranged) | 정밀한 사수 | 어둠 속에서도 흔들리지 않는 시야를 확보하고 적의 접근을 원천 봉쇄하는 화망을 구축합니다. |
| 서포터 (Supporter) | 고대의 조력자 | 잊혀진 룬의 지혜와 마력의 흐름을 조율하여 버민킨의 오염으로부터 군단을 보존합니다. |

### 3.2 유닛 등급

유닛 타입마다 3단계 등급이 있습니다. 등급이 높을수록 해당 병종의 스페셜리스트로서 전술의 핵심 역할을 합니다.

| 등급 | 성격 | 설명 |
|---|---|---|
| 1티어 | 일반 | 유닛 타입의 기본 역할을 수행하는 일반 등급 |
| 2티어 | 베테랑 | 유닛 타입의 장점을 살린 베테랑 등급 |
| 3티어 | 전문가 | 유닛 타입의 특기를 극대화한 전문가 등급 |

### 3.3 특성·스킬 슬롯

모든 드워프 유닛은 다음 슬롯을 가지며, 슬롯은 **레벨이 오르면서 하나씩 열립니다.** (게임 데이터 구조 기준)

| 슬롯 | 개수 | 설명 |
|---|---|---|
| 특성 | 6 | 상시 적용되는 패시브 효과 |
| 액티브 스킬 | 3 | SP를 소모해 직접 사용하는 기술 |

게임 데이터의 '특성 2 + 패시브 스킬 4'는 하나로 합쳐 **특성 6칸**으로 관리합니다.

| 레벨 | 열리는 슬롯 | 누적 (특성 / 액티브) |
|---|---|---|
| 1 | 특성 1, 액티브 1 | 1 / 1 |
| 2 | 특성 2 | 2 / 1 |
| 3 | 특성 3 | 3 / 1 |
| 4 | 액티브 2 | 3 / 2 |
| 5 | 특성 4 | 4 / 2 |
| 6 | 특성 5 | 5 / 2 |
| 7 | 액티브 3 | 5 / 3 |
| 8 | 특성 6 | 6 / 3 |
| 9~10 | 없음 (파라미터만 성장) | 6 / 3 |

> 게임 데이터의 특성·패시브 슬롯 통합은 [개발 반영 필요](99_review_notes.md#13-개발-반영-필요) 항목입니다.

## 4. 버민킨

### 4.1 유닛 타입

| 타입 | 특징 | 역할 |
|---|---|---|
| 보병 | 가장 머릿수가 많은 기본 유닛. 수적 우위로 압박합니다. | 근접·원거리 기본 공격, 높은 MOV를 활용한 측면 기동, 시야 밖 기습, 지형지물을 무시한 난입 등 전술적 토대를 형성합니다. |
| 괴수 | 거대한 덩치와 높은 HP를 가진 돌파형 유닛. | 전선을 돌파하거나 사망 시 역병 지대를 생성하는 등 전장 구도를 물리적으로 파괴합니다. |
| 영체 | 물리 법칙을 초월하거나 정신 공격·마법 능력을 가진 존재. | HIT 감소, 타겟팅 분산, 공포 유발, MOV 감소 등 강력한 디버프로 아군 효율을 떨어뜨립니다. |
| 병기 | 조잡하지만 파괴적인 기술력이 집약된 기계·공학 유닛. | DEF 파괴, 기름으로 이동 제약, 폭발로 광역 장비 기능 정지 등 아군 방어 체계를 직접 무력화합니다. |
