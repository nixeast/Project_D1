# 08. 특성 · 스킬

[← 목차](README.md)

- **특성:** 조건을 만족하면 상시 적용되는 패시브 효과입니다.
- **액티브 스킬:** SP를 소모해 직접 사용하는 기술입니다.

> 드워프는 병종별 고유 세트, 버민킨은 유닛 타입별 특성 풀과 클랜별 액티브 풀에서 병종마다 배정합니다. 특성·스킬 수치(SP 소모, 쿨타임, 범위, Potency)는 밸런싱 때 정합니다. ([확인 필요](99_review_notes.md#12-밸런싱-때-정할-수치))

## 1. 스킬 파라미터

| 파라미터 | 정의 | 적용 |
|---|---|---|
| 소모 정신력 (SP Cost) | 스킬 발동 시 요구되는 내적 에너지 수치 | 육체적·정신적 한계를 끌어쓰는 개념. 강력한 기술일수록 높은 SP를 소모합니다. |
| 재사용 대기시간 (Cooldown) | 스킬 사용 후 다시 쓸 수 있을 때까지의 턴 수 | 턴제 전투의 전략적 균형을 유지하는 핵심 지표 |
| 정신 집중 범위 (Focus Range & AoE) | 스킬이 영향을 미치는 거리와 타일 범위 | 드워프의 '인접 타일 보너스'와 연계해 자신 주변이나 특정 구역에 효과를 발휘 |
| 파라미터 증폭 수치 (Potency) | 기본 5대 파라미터(ATK, HIT, DEF, EVA, MOV)를 일시적으로 변화시키는 값 | 예: 탱커가 '방어 숙련' 효과를 극대화, 근접 딜러가 공격력을 일시 증폭 |
| 의지 유지 조건 (Will Persistence) | 스킬 효과가 지속되기 위한 상태 조건 | 예: 이동하지 않아야 유지, 특정 SP 이하로 떨어지면 해제 |
| 이동 상태 조건 (Movement Status Condition) | 스킬 사용 직전·직후의 이동 여부·거리에 따른 발동 가능 여부와 위력 보정 | 예: 이동 후 사용 시 효율 상승, 이동하면 효과 해제 |

## 2. 드워프

드워프는 **병종마다 고유한 특성·스킬 세트**를 가집니다. 병종마다 특성 6개와 액티브 스킬 3개이며, 슬롯은 레벨에 따라 열립니다. ([07. 유닛 § 특성·스킬 슬롯](07_units.md#33-특성스킬-슬롯))

- 병종별 구성은 `data_unit.csv`의 `trait_01~06`, `activeSkill_01~03`에, 이름·설명·아이콘은 `Assets/Resources/data_skill.csv`에 있습니다. 두 데이터는 영문 이름으로 연결됩니다.
- 한국어 이름은 모집 데이터에 있는 대표 특성(첫 번째 특성)을 빼면 모두 번역 이름입니다.
- **출처** 열의 의미
  - GDD: 이전 기획(유닛 타입별 공용 풀)의 효과를 옮겨 온 것
  - 신규: 데이터에 이름만 있어 새로 설계한 효과 (2026-11-20 검토 확정)

### 2.1 둠 브레이커 (Doom Breaker)

둠 테마에 대응하는 특성입니다. 해당 둠 테마의 미션에서 이 유닛은 **미션 기믹의 불이익을 받지 않습니다(완전 면역).** 병종마다 2종을 가지므로, 미션에 맞춰 병종을 고르는 전략이 생깁니다.

| 특성 | 데이터 이름 | 대응 둠 테마 | 대표 기믹 |
|---|---|---|---|
| 둠 브레이커: 역병 | Doom Breaker: Blight | 오염의 역병 | 독기 (매 턴 HP 감소) |
| 둠 브레이커: 변이 | Doom Breaker: Variant | 차원석 변이 | 마력 공명 (공간 왜곡 텔레포트) |
| 둠 브레이커: 터널 | Doom Breaker: Tunnels | 지하 터널 | 심연의 어둠 (시야 감소, 기습) |
| 둠 브레이커: 영혼 | Doom Breaker: Soul | 영혼 수확 | 영혼의 갈취 (회복 효율 감소, HP 갈취) |
| 둠 브레이커: 분쇄 | Doom Breaker: Grinding | 재앙의 톱니바퀴 | 분쇄 작업 (DEF 파괴, 반사 피해) |
