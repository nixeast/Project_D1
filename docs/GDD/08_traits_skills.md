# 08. 특성 · 스킬

[← 목차](README.md)

- **특성:** 조건을 만족하면 상시 적용되는 패시브 효과입니다.
- **액티브 스킬:** SP를 소모해 직접 사용하는 기술입니다.

> 특성·스킬의 구체적 수치는 아직 정해지지 않았습니다. 게임 데이터(`data_unit.csv`)의 특성·스킬 이름은 이 문서와 다르게 정의되어 있으며, 대조는 별도로 진행합니다. ([확인 필요](99_review_notes.md#11-기획-결정-필요))

## 1. 스킬 파라미터

| 파라미터 | 정의 | 적용 |
|---|---|---|
| 소모 정신력 (SP Cost) | 스킬 발동 시 요구되는 내적 에너지 수치 | 육체적·정신적 한계를 끌어쓰는 개념. 강력한 기술일수록 높은 SP를 소모합니다. |
| 재사용 대기시간 (Cooldown) | 스킬 사용 후 다시 쓸 수 있을 때까지의 턴 수 | 턴제 전투의 전략적 균형을 유지하는 핵심 지표 |
| 정신 집중 범위 (Focus Range & AoE) | 스킬이 영향을 미치는 거리와 타일 범위 | 드워프의 '인접 타일 보너스'와 연계해 자신 주변이나 특정 구역에 효과를 발휘 |
| 파라미터 증폭 수치 (Potency) | 기본 5대 파라미터(ATK, HIT, DEF, EVA, MOV)를 일시적으로 변화시키는 값 | 예: 탱커가 '방어 숙련' 효과를 극대화, 근접 딜러가 공격력을 일시 증폭 |
| 의지 유지 조건 (Will Persistence) | 스킬 효과가 지속되기 위한 상태 조건 | 예: 이동하지 않아야 유지, 특정 SP 이하로 떨어지면 해제 |
| 이동 상태 조건 (Movement Status Condition) | 스킬 사용 직전·직후의 이동 여부·거리에 따른 발동 가능 여부와 위력 보정 | 예: 이동 후 사용 시 효율 상승, 이동하면 효과 해제 |

## 2. 드워프

### 2.1 특성

| 타입 | 기획 의도 | 특성 | 효과 |
|---|---|---|---|
| 탱커 | 전열의 방패, 끝까지 무너지지 않는 단단한 전열 | 강철의 결속 | 인접한 아군 유닛 하나당 자신의 DEF가 일정 수치만큼 상시 증가 |
| | | 부동의 자세 | 이동하지 않고 턴을 종료하면 다음 턴 시작 전까지 DEF 보너스 추가 |
| | | 방어 숙련 | 정면에서 오는 공격에 대해 DEF 효율이 상시 강화 |
| | | 무거운 발걸음 | 기본 MOV는 낮지만 밀쳐내기 등 위치 변화 효과에 면역 |
| 근접 딜러 | 필사의 칼날, 적진의 심장을 향해 뛰어드는 수복의 선봉장 | 선봉장의 기세 | 전장에 적 유닛이 아군보다 많으면 ATK 상시 상승 |
| | | 도전자 | 자신보다 현재 체력이 높은 적을 공격할 때 HIT 보너스 |
| | | 난전의 대가 | 인접 타일에 적이 2기 이상이면 EVA 상시 증가 |
| | | 경량화 갑주 | 기본 MOV에 상시 보너스 |
| 원거리 딜러 | 정밀한 사수, 어둠 속에서도 흔들리지 않는 시야로 화망 구축 | 침착한 조준 | 이동하지 않고 공격하면 HIT와 ATK 상시 강화 |
| | | 거리 유지 | 공격 대상과의 거리가 멀수록 ATK 효율 증가 |
| | | 위험 감지 | 주변 1타일 내에 적이 없으면 EVA 상시 상승 |
| | | 필중의 조준 | 기본 HIT에 보너스 |
| 서포터 | 고대의 조력자, 룬의 지혜와 마력을 조율하여 군단을 보존 | 룬의 가호 | 인접(주변 1타일) 아군의 DEF와 EVA 상시 상승 |
| | | 비전 엔진 | 인접 아군은 매 턴 시작 시 MOV 보너스 |
| | | 지혜의 전수 | 인접 아군의 HIT 상시 보정 |
| | | 보호의 룬 | 서포터와 인접한 아군은 DEF 추가 증가 |

> 서포터 특성 '룬의 가호'와 '보호의 룬'은 둘 다 인접 아군 DEF를 올려 효과가 겹칩니다. 또 특성 '지혜의 전수'와 같은 이름의 액티브 스킬이 있습니다. ([확인 필요](99_review_notes.md#11-기획-결정-필요))

### 2.2 액티브 스킬

| 타입 | 스킬 | 효과 |
|---|---|---|
| 탱커 | 방패 밀치기 | 적을 뒤로 밀쳐내며 공격력을 약화. 이동 후 사용 시 효율 상승 |
| | 최후의 저항 | 최상급 방어력 보너스와 면역을 얻지만, 이동하면 즉시 해제 |
| | 철벽의 진형 | 자신을 포함한 주변 아군의 방어력을 높이고 진형을 고정 |
| | 도발의 함성 | 주변 적들의 명중률을 낮추고 자신을 공격하도록 유도 |
| | 뿌리박기 | 이동하지 않는 대가로 방어력을 중첩 강화 |
| 근접 딜러 | 수복의 돌진 | 반드시 이동과 연계. 경로상의 적들을 타격하고 약화 |
| | 광폭한 휘두르기 | 자신 주변의 모든 적을 동시에 공격하고 회피력을 낮춤 |
| | 선봉장의 일격 | 자신보다 체력이 높은 적에게 폭발적인 피해 |
| | 경량화 가속 | 일시적으로 이동 능력과 회피력을 높임 |
| | 필사의 칼날 | 남은 정신력에 비례해 큰 피해, 대신 자신의 방어력 감소 |
| 원거리 딜러 | 집중 조준 | 이동을 포기하는 대신 다음 턴의 명중률과 공격력을 대폭 높임 |
| | 철갑 탄환 | 적의 방어력을 무시하고 타격하며 이동을 봉쇄 |
| | 섬광 연막탄 | 특정 지점에 연막을 쳐 적의 명중률을 떨어뜨리고 시야 차단 |
| | 위험 감지 도약 | 인접한 적이 있을 때만 발동. 후방으로 회피하며 방어 태세 |
| | 포격 지원 | 넓은 범위에 화상 피해. 시전 중 피격되면 취소될 수 있음 |
| 서포터 | 보호의 룬 각인 | 아군 한 명에게 강력한 방어막. 대상과 멀어지면 해제 |
| | 비전 엔진 과부하 | 주변 아군의 이동력과 다음 공격의 명중률을 일시적으로 높임 |
| | 지혜의 전수 | 아군의 SP를 즉시 회복시켜 스킬 순환을 도움 |
| | 대지의 룬 | 넓은 구역 내 아군의 방어력을 높이고 해로운 이동 제약 해제 |
| | 룬의 결속 | 자신과 아군의 방어력을 하나로 묶어 평균치를 높임. 시야가 가려지면 해제 |

## 3. 버민킨

### 3.1 특성 (유닛 타입별)

| 타입 | 기획 의도 | 특성 | 효과 |
|---|---|---|---|
| 보병 | 높은 기동력과 수적 우위를 활용한 전술적 압박 | 비열한 협공 | 공격 대상과 인접한 아군 버민킨 하나당 HIT 상시 증가 |
| | | 물량의 공포 | 인접 타일에 아군 버민킨이 3기 이상이면 ATK 보너스 |
| | | 날랜 발바닥 | 기본 MOV 보너스, 험지 이동 페널티 무시 |
| | | 교란의 걸음 | 적과 인접하여 이동을 종료하면 그 적의 EVA를 다음 턴 시작 전까지 감소 |
| | | 생존 본능 | 현재 체력 30% 이하일 때 EVA 대폭 상승 |
| 괴수 | 전선 돌파 및 강력한 물리적 파괴력 | 무자비한 돌진 | 직선으로 3타일 이상 이동 후 공격 시 ATK Potency 대폭 상승 |
| | | 비대해진 가죽 | 기본 DEF가 매우 높고, 원거리 공격에 추가 방어 효율 |
| | | 역병의 진원지 | 주변 1타일 내 적의 DEF를 상시 약화시키는 오라 |
| | | 압도적 질량 | 공격 성공 시 적을 1타일 밀쳐내고 MOV를 일시적으로 고정 |
| | | 고통의 역류 | 피격 시 받은 데미지 일부를 주변 적에게 반사, 자신의 ATK 1턴간 상승 |
| 영체 | 물리 법칙 초월 및 정신 공격으로 효율 저하 | 실체 없는 형상 | 물리 공격에 대해 높은 EVA 보너스, 지형지물 통과 이동 |
| | | 정신적 잠식 | 공격 시 적의 HIT를 영구적으로 소폭 감소 |
| | | 공포의 파동 | 주변 2타일 내 적의 ATK 효율 상시 감소 |
| | | 의지 파괴 | 스킬 적중 시 적의 의지 유지 조건을 강제로 해제하여 지속 스킬 중단 |
| | | 환영의 장막 | 인접한 아군 버민킨의 EVA 상시 보정 |
| 병기 | 기술력을 활용한 방어 체계 무력화 | 강철 파쇄기 | 공격 시 대상의 DEF를 무시하는 관통 효과 상시 보유 |
| | | 정밀 조준 장치 | 이동하지 않고 사격하면 HIT와 사거리 보너스 |
| | | 과열된 엔진 | 스킬 재사용 대기시간 동안 주변 타일에 지속 화염 피해 |
| | | 유독성 연료 유출 | 이동 경로에 기름 타일을 생성하여 적의 MOV 크게 제한 |
| | | 충격 보정 장치 | 원거리 공격 시 대상과 가까울수록 ATK Potency 추가 증폭 |

### 3.2 액티브 스킬 (클랜별)

| 클랜 | 컨셉 | 스킬 | 효과 |
|---|---|---|---|
| 소속 없음 | — | 비열한 투척 | [원거리 공격] 오물 주머니로 피해를 주고 1턴간 HIT 소폭 감소 |
| | | 숫자 밀어붙이기 | [근접 공격] 자신과 인접한 아군 버민킨 하나당 추가 피해 |
| | | 공포의 찍찍거림 | [범위 디버프] 주변 2타일 내 드워프의 ATK 1턴간 감소 |
| | | 쥐구멍 습격 | [이동 및 공격] 2타일 내 빈 공간으로 즉시 도약하여 근접한 적 공격 |
| | | 무자비한 갉아먹기 | [강력한 근접 공격] 피해를 주고 낮은 확률로 1턴간 이동불가(Root) |
| 역병의 손아귀 | 부패와 독극물 — 식수원 오염, 지속 피해(DoT) | 부패의 숨결 | 범위 내 적들의 DEF를 매 턴 영구 감소 |
| | | 역병 사체 투척 | 지정 타일을 역병 지대로 만듦. 진입한 적은 지속적으로 HP 감소 |
| | | 독포자 폭발 | SP를 소모해 중독 부여. 중독된 적은 매 턴 ATK 감소 |
| | | 오염된 쥐 떼 소환 | 버민 보병을 소환하여 적의 이동을 방해하고 압박 |
| | | 점액질 바닥 | 지면에 오물을 뿌려 적의 MOV 감소, 이동 경로 제약 |
| 변이의 맥박 | 생체 실험과 차원석 — 개조와 재생력 | 차원석 과부하 | 일시적으로 자신의 ATK와 MOV 대폭 증폭. 종료 후 SP 고갈 또는 자해 피해 |
| | | 세포 재생 | 매 턴 시작 시 잃은 HP 일부 회복, 주변 버민에게도 약한 재생 부여 |
| | | 불안정한 변이 | 피격 시 일정 확률로 MOV 보너스를 얻고 무작위 인접 타일로 이동하여 회피 |
| | | 자폭 돌격 | 체력이 일정 이하가 되면 적진으로 돌진해 자폭. 광역 피해와 장비 기능 정지 |
| | | 거대화 주입 | 아군 하나를 일시적으로 거대화. HP·DEF 대폭 상승, 밀쳐내기 부여 |
| 그림자의 비수 | 암살과 사보타주 — 은신·기습, 보급로 차단 | 그림자 숨기 | 안개나 지형지물로 은신. 은신 중에는 타겟팅에서 제외 |
| | | 급소 찌르기 | 은신을 해제하며 공격하면 HIT와 무관하게 반드시 명중, 추가 피해 |
| | | 함정 설치 | 보이지 않는 함정 설치. 밟은 적은 이동 정지, EVA 급락 |
| | | 연막탄 | 주변을 연기로 가려 아군 버민의 EVA 상승, 적의 HIT를 최저 수치로 고정 |
| | | 기술자 암살 | 적 서포터를 우선 노림. 적중 시 SP 회복 방해 또는 쿨타임 증가 |
| 영혼의 갈고리 | 공포와 강령술 — 영혼 구속, 죽은 자를 일으킴 | 영혼 갈취 | 가한 피해의 일정 비율만큼 HP 회복 또는 SP 충전 |
| | | 공포의 비명 | 광역으로 주변 적들의 MOV와 ATK 감소 |
| | | 망령 부활 | 쓰러진 버민 유닛을 낮은 HP의 영체 유닛으로 부활 |
| | | 환영 복제 | 피해를 주지 못하는 허상을 소환하여 타겟팅을 분산 |
| | | 절망의 저주 | 대상과 인접한 드워프들의 DEF와 EVA를 동시에 약화 |
| 기술의 톱니바퀴 | 조잡한 기계 공학 — 드워프 기술 복제, 거대 병기 | 차원 에너지 포격 | 먼 거리에 광역 피해. 지형 파괴 또는 화재 효과 |
| | | 장갑 파쇄 | 적의 DEF를 일시 무효화하거나 영구 파괴 |
| | | 고압 증기 방출 | 주변 1타일에 증기를 뿜어 밀쳐내고, 받는 피해량 증가 |
| | | 자동 포탑 가동 | 매 턴 가장 가까운 적을 자동 사격하는 포탑 설치 |
| | | 기름 발사 | 지면에 기름을 뿌려 MOV 제약, 화염 공격 시 추가 폭발 유도 |
