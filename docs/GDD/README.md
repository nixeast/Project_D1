## 문서 원칙

1. **한 내용은 한 곳에만 씁니다.** 다른 챕터에서 필요하면 링크로 참조합니다.
2. **수치·목록 데이터의 원본은 게임 데이터입니다.** 유닛 스탯, 미션 적 구성, 고용 비용 등은 [`Assets/05_csv/`](../../Assets/05_csv/)에서 관리하고, GDD에는 규칙과 의도만 적습니다.
3. **결정되지 않은 내용은 `확인 필요`로 표시합니다.** 모든 항목은 [99. 확인 필요](99_review_notes.md#1-확인-필요)에 모아 두고, 결정되면 본문을 고친 뒤 목록에서 지웁니다.
4. **기획이 바뀌면 GDD를 먼저 고칩니다.** 바뀐 이유는 [98. 결정 기록](98_decision_log.md)에 남깁니다.
