# 05. 탐사 플레이 · 이벤트

[← 목차](README.md)

## 1. 탐사 플레이 개요

- 미션을 시작하면 **탐사 플레이**로 진행됩니다. (버민킨 대공세 미션은 탐사 없이 전투만 진행)
- 탐사는 원정대에게 **이벤트**가 발생한 상황을 기반으로 한 **선택지 플레이**입니다.
- 이벤트 상황은 텍스트와 삽화로 묘사하여 플레이어의 선택을 돕습니다.
- 선택 결과에 따라 전투가 발생하면 [06. 전투](06_battle.md)로 전환됩니다.

### 1.1 탐사 진행 구조

```
출발 (보급품 지급) → 이벤트 1 → 이벤트 2 → … → 이벤트 N → 미션 전투 → 결과 → 캠프 귀환
                       └ 조우전 (이기면 다음 이벤트로)
```

| 항목 | 규칙 |
|---|---|
| 이벤트 수 | 미션 소요 일수만큼 진행합니다. 하루에 이벤트 1개: 쉬움 2개, 보통 3개, 어려움·매우 어려움 4개. ([03 §3.1](03_campaign.md#31-미션-소요-일수)) 이벤트의 '시간 소요'는 날짜만 추가로 지나가게 하고 이벤트 수를 늘리지 않습니다. |
| 이벤트 순서 | 미션이 발생한 거점의 이벤트(보상·과제) 중에서 무작위로 나옵니다. 한 미션 안에서 같은 이벤트는 다시 나오지 않습니다. |
| 출발 보급품 | 미션을 시작할 때마다 이벤트 수에 비례한 보급품을 받습니다(초기값 이벤트 1개당 2). 남은 보급품은 미션이 끝나면 사라지며 다음 미션으로 넘어가지 않습니다. |
| 보급품 0 | 보급품이 드는 선택지는 고를 수 없습니다. 보급품이 0인 채로 다음 이벤트로 넘어갈 때마다 원정대 전원이 **굶주림** 피해(공포 증가, HP 감소)를 받습니다. 모든 이벤트에는 보급품이 필요 없는 선택지가 1개 이상 있어야 합니다. |
| 조우전 | 이벤트 선택지로 일어나는 전투입니다. 그 미션의 적 구성에서 일부(초기값 절반)를 뽑아 적 전멸(Elimination)로 진행하며, 제한 턴이 있습니다. 이기면 다음 이벤트로 이어 갑니다. |
| 미션 전투 | 마지막 이벤트가 끝나면 미션 데이터의 본 전투(타입·목표·적 구성)를 치릅니다. 이기면 미션 완료입니다. |
| 미션 실패 | 조우전이나 미션 전투에서 지면 미션 실패입니다. 결과는 [둠 미션 패배](03_campaign.md#4-미션)와 같습니다. |
| 미션 포기 | 이벤트와 이벤트 사이에는 언제든 포기할 수 있습니다(전투 중에는 불가). '포기·퇴각' 선택지도 같습니다. 결과는 미션 실패와 같습니다. |
| 실패·포기 시 획득물 | 탐사 중 이미 얻은 골드·명예·무쇠 정수·아이템과 XP는 유지합니다. 미션 완료 보상, 완료 XP, 위협도 감소만 받지 못합니다. |

## 2. 이벤트 규칙

| 항목 | 규칙 |
|---|---|
| 발생 거점 | 모든 이벤트는 미션이 발생한 거점별로 분류됩니다. |
| 보상 이벤트 | 선택지 중 하나를 골라 자원 보상이나 버프 같은 혜택을 받는 이벤트입니다. |
| 과제 이벤트 | 선택지 중 하나를 골라 발생한 과제를 해결해야 하는 이벤트입니다. 직접 전투를 치를지, 자원을 소모해 해결할지 선택합니다. |

## 3. 선택지 규칙

| 항목 | 규칙 |
|---|---|
| 선택지 수 | 2지 선다형과 4지 선다형 두 가지 타입이 있습니다. |
| 비용 | 선택지 비용은 원정대의 **탐사 자원**으로 지불하며 즉시 차감됩니다. 1종류 이상의 자원이 필요할 수 있습니다. 탐사 자원 목록은 [03. 캠페인 § 자원](03_campaign.md#5-자원)을 참고합니다. |

### 선택지 영향

| 영향 | 설명 |
|---|---|
| 전투 발생 | 전투가 발생할 수 있습니다. |
| 원정대 버프 | 원정대의 유닛들이 버프를 받을 수 있습니다. |
| 원정대 디버프 | 원정대의 유닛들이 디버프를 받을 수 있습니다. |
| 자원 획득 | 탐사 자원을 획득할 수 있습니다. |
| 자원 소실 | 탐사 자원을 잃을 수 있습니다. |
| 공포 변화 | 원정대 유닛의 공포 수치가 오르거나 내립니다. ([07. 유닛 § 공포](07_units.md#12-공포)) |

### 이벤트 문구의 해석

이벤트 선택지의 표현은 분위기를 위한 것이며, 실제 처리는 아래 규칙을 따릅니다.

| 이벤트 문구 | 실제 처리 |
|---|---|
| 행동력 소모 | 보급품 소모 |
| 시간 소요·시간 소모 | 둠 페이즈 카운트 추가 차감 ([03. 캠페인 § 둠 페이즈](03_campaign.md#3-둠-페이즈)) |
| 식량, 물, 석탄, 연료, 자재 등의 획득·소모 | 보급품 획득·소모 |
| 공포 감소·방지, 사기 소모·저하 | 유닛 공포 수치 감소·증가 |
| 명예 획득·소모 | 명예 자원 획득·소모 |
| 경험치 획득 | 원정대 전원에게 XP 지급 ([07. 유닛 § 경험치 획득](07_units.md#22-경험치-획득)) |
| 아이템·장비 획득 | 캠프 창고에 아이템 추가 |
| 시야 확보·시야 버프 | 다음 전투에서 시야 범위가 늘어나는 버프 |
| 정신력 버프·소모 | 유닛 SP 회복·감소 |
| 지식 획득 (비문 해석, 실험 일지, 기억·기록 등) | 원정대 전원에게 XP 지급 (경험치 획득과 같음) |
| 광원 범위 증가 | 시야 버프와 같음 |
| 기술 판정, 해킹, 성공·실패, ~확률, ~가능성 | **확률 판정**. 선택지마다 기본 성공률이 있고, 원정대에 맞는 병종(예: 수리·해킹은 공병)이 있으면 성공률이 오릅니다. 실패하면 선택지에 적힌 불이익(대개 전투)이 일어납니다. |
| 특수 아이템 소모 (방독면, 보안 카드, 폭탄 등) | 보급품 추가 소모 |
| 특수 아이템 획득 (광역 피해 아이템, 특수 아이템 등) | 다음 전투에서 한 번 쓰는 효과 (예: 광역 피해 1회) |
| 전투 조건 변화 (지형 변화, 유리한 조건 전투, 적 약화·적 방어 감소, 적 강화 상태 대결) | **다음 전투 수정치**: 아군 버프, 적 디버프·강화, 아군 선공 |
| 지원군, 지원 요청 | 다음 전투에 임시 NPC 유닛 1기 합류 |
| 속성 부여, 피해 면역 | 다음 전투 버프 |
| 체력 소모, 피해, 부상 | 원정대 전원 최대 HP의 일정 비율(초기값 20%) 감소. HP는 1 아래로 내려가지 않습니다. HP 유지 방식은 [07 §1.3](07_units.md#13-쓰러짐부상회복)을 따릅니다. |
| 회복, 치료, 휴식·컨디셔닝 | 원정대 전원 최대 HP의 일정 비율(초기값 20%) 회복 |
| 디버프 제거, 버프 제거 | 원정대가 받은 디버프 해제 / 적의 버프 해제 |
| 유닛 일시 이탈 | 무작위 유닛 1명이 다음 전투에 출전하지 못함 |
| 지도, 이동 효율 | 이번 미션의 다음 이벤트 1회 보급품 비용 감소·면제 |
| 채굴 효율 | 이번 미션의 다음 무쇠 정수 획득량 증가 |
| 자원 지속 획득 (자동 생산 등) | 이번 미션의 남은 이벤트마다 보급품 소량 획득 |
| 자원 전환 (결정 변환, 물자 교환) | 한 탐사 자원을 다른 탐사 자원으로 교환 |
| 업그레이드 비용 감소 | 다음 유닛 고용 비용 감소 |
| 미션 밖으로 번지는 불이익 (요새 손상, 차원 이상 발생, 버민킨 분노 등) | 위협도 증가 (초기값 +5%, [03. 캠페인 § 위협도](03_campaign.md#32-위협도와-대공세-강화)) |
| 경로 단절, 미션 실패 위험 (포기·퇴각) | 미션 포기 ([§1.1](#11-탐사-진행-구조)) |

> 성공률, 피해·회복 비율, 비용 감소량 같은 세부 수치는 이벤트 데이터에 둡니다.

## 4. 이벤트 리스트

거점별 이벤트 60종(거점마다 보상 5, 과제 5)의 원고는 [05a. 이벤트 리스트](05a_events.md)에 있습니다.
