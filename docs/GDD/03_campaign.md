# 03. 캠페인

[← 목차](README.md)

## 1. 기획 의도

| 의도 | 설명 |
|---|---|
| 전략적 병종 조합을 통한 전술적 깊이 | 탱커, 근접 딜러, 원거리 딜러, 서포터로 명확하게 구분된 병종의 특징을 활용하는 전술적 선택이 핵심입니다. 유닛 간 시너지를 설계하는 재미를 제공합니다. |
| 단계적 성장을 통한 성취감 | 유닛 등급과 레벨 시스템으로 캠페인 진행에 따른 점진적 성장을 의도합니다. 자원을 관리하고 부대를 육성하여 더 어려운 스테이지를 극복하는 경험을 목표로 합니다. |

**캠페인 목표:** 버민킨에게 빼앗긴 거점들을 수복하고, 군단을 강화하여 버민킨 대공세를 막아내는 것.

## 3. 둠 페이즈

캠페인은 **둠 페이즈**라는 챕터 단위로 진행됩니다. 둠 페이즈 1개는 게임 속 **10일**이며, 캠페인은 둠 페이즈 5개(50일)로 구성됩니다.

| 단계 | 규칙 |
|---|---|
| 시작 | 둠 페이즈가 시작되면 해당 페이즈에 속한 둠 미션들이 발생합니다. |
| 카운트다운 | 미션을 하나 진행할 때마다 난이도에 따라 날짜가 지나갑니다(아래 표). 탐사 이벤트에서 '시간 소요' 선택지를 고르면 1일이 추가로 지나갑니다. |
| 종료 | 둠 카운트가 0이 되면(10일이 지나면) 현재 둠 페이즈가 종료됩니다. |
| 결산 | 해당 페이즈 동안 클리어하지 못한 둠 미션 1개당 **위협도 게이지**가 10% 증가합니다. (게이지 0~100%) |
| 버민킨 대공세 | 둠 페이즈가 끝날 때마다(10·20·30·40·50일차) 아이언풋 요새에서 버민킨 대공세 미션 1개가 강제로 발생합니다. 플레이어는 이 전투를 피할 수 없습니다. |
| 대공세 패배 | 대공세에서 패배하면 요새가 함락되어 즉시 게임 오버입니다. |
| 위협도 적용 | 위협도가 높을수록 다음 버민킨 대공세가 강해집니다. |
| 엔딩 | 50일차의 마지막 대공세 '왕의 관문'의 결과가 엔딩으로 이어집니다. |

```
[둠 페이즈 1~5 반복, 각 10일]
둠 페이즈 시작 → 둠 미션 발생 → 미션 진행(카운트 차감) ×N → 카운트 0 → 결산(미클리어 수만큼 위협도 +)
     ▲                                                                        │
     └──────────── 버민킨 대공세 (위협도만큼 강화) ◀──────────────────────────┘
                   └─ 5번째(50일차) '왕의 관문' → 엔딩
```

| 둠 페이즈 | 종료 시점 | 버민킨 대공세 |
|---|---|---|
| 1 | 10일차 | 외성벽 결사 사수 |
| 2 | 20일차 | 지하 침투로 봉쇄 |
| 3 | 30일차 | 무기고 탈환전 |
| 4 | 40일차 | 중앙 광장 최후 항전 |
| 5 | 50일차 | 왕의 관문 (최종전) |

### 3.1 미션 소요 일수

| 미션 난이도 | 소요 일수 |
|---|---|
| 쉬움 | 2일 |
| 보통 | 3일 |
| 어려움 | 4일 |
| 매우 어려움 | 4일 |
| 탐사 이벤트 '시간 소요' | +1일 |

페이즈에 남은 일수보다 오래 걸리는 미션은 고를 수 없습니다. 남은 일수로 할 수 있는 미션이 없으면 페이즈가 끝납니다.

### 3.2 위협도와 대공세 강화

| 항목 | 값 (초기값) |
|---|---|
| 위협도 증가 | 페이즈 종료 시 클리어하지 못한 둠 미션 1개당 +10% |
| 위협도 감소 | 둠 미션 클리어 시 쉬움 -5%, 보통 -10%, 어려움 -15%, 매우 어려움 -20% |
| 게이지 범위 | 0 ~ 100% |

**밸런스 목표:** 페이즈마다 할 수 있는 미션을 모두 클리어하면 마지막 대공세('왕의 관문') 직전 위협도가 **30% 안팎**이 되도록 합니다. 한 페이즈에 미션 5개 중 일부만 할 수 있으므로(소요 일수 때문), 잘해도 약간의 강화는 남고, 패배가 쌓이면 70~100%까지 오릅니다.

| 플레이 (초기값 기준) | 페이즈 1~5 종료 시 위협도 |
|---|---|
| 할 수 있는 미션을 모두 클리어 | 0 → 20 → 20 → 30 → 30% |
| 페이즈마다 1개 패배 | 10 → 30 → 40 → 65 → 90% |

위협도가 높을수록 다음 대공세에 아래 강화가 모두 적용됩니다.

| 강화 | 초기값 |
|---|---|
| 적 수 증가 | 위협도 20%마다 적 유닛 +1 |
| 적 등급 상승 | 위협도 50% 이상이면 일반 적의 25%를 정예로 교체 |
| 적 파라미터 상승 | 위협도 10%마다 모든 적의 ATK·DEF +2% |
| 기믹 강화 | 위협도 10%마다 기믹의 피해·감소 수치 +10% (예: 성문 내구도 감소량, 지속 피해). 위협도 50% 이상이면 증원·포격 등 턴 간격이 1턴 짧아짐 (최소 1턴) |

모든 대공세에 같은 강화 규칙을 적용합니다.

## 4. 미션

| 항목 | 규칙 |
|---|---|
| 발생 | 둠 페이즈가 시작될 때마다 주요 거점에서 정해진 미션들이 발생합니다. 페이즈가 높아질수록 난이도 높은 미션이 등장합니다. |
| 선택 | 플레이어는 등장한 미션 중 원하는 것을 골라 도전할 수 있습니다. |
| 해결 | 미션을 클리어하면 해결 처리되어 버민킨 공세 위협도가 낮아지고, 정해진 보상을 획득합니다. |
| 실패 | 둠 미션에서 패배해도 소요 일수는 지나가며, 그 미션은 사라져 다시 도전할 수 없습니다. 페이즈 결산 때 클리어하지 못한 미션으로 계산합니다. 탐사 중 조우전 패배와 미션 포기도 같게 처리합니다. ([05 §1.1](05_exploration.md#11-탐사-진행-구조)) |
| 구성 | 미션은 **탐사 이벤트**(소요 일수만큼)를 거친 뒤 마지막에 **미션 전투**를 치릅니다. 탐사 중 이벤트로 조우전이 일어날 수 있습니다. 버민킨 대공세 미션은 전투 플레이만 진행합니다. ([05 §1.1](05_exploration.md#11-탐사-진행-구조)) |
| 캠프 귀환 | 미션 전투에서 이기거나, 미션에 실패하거나, 포기하면 캠페인으로 돌아갑니다. |

- 전투 플레이 규칙 → [06. 전투](06_battle.md)
- 미션 목록 → [04. 미션](04_missions.md)

> 페이즈마다 등장하는 둠 미션과 대공세가 발생하는 페이즈는 [`Assets/05_csv/data_mission.csv`](../../Assets/05_csv/data_mission.csv)의 `appearPhase` 열이 원본입니다. (예: `2/3` = 페이즈 2와 3에 등장)

| 대공세 결과 | 처리 |
|---|---|
| 승리 | 다음 둠 페이즈가 시작됩니다. 5번째 '왕의 관문'에서 승리하면 캠페인 완료(엔딩)입니다. |
| 패배 | 게임 오버. 결과 화면 뒤 새 캠페인(1일차)으로 시작합니다. |

## 5. 자원

| 자원 | 등급 | 캠페인 용도 | 탐사 용도 |
|---|---|---|---|
| 골드 | 범용 | 유닛 고용 | 위험을 회피하거나 기회를 얻는 선택지 비용 |
| 명예 | 희소 | 유닛 고용 | 큰 위험을 회피하거나 큰 기회를 얻는 선택지 비용 |
| 무쇠 정수 | 최상위 희소 | 유닛 고용 | 치명적인 위험을 회피하거나 특별한 기회를 얻는 선택지 비용 |
| 보급품 | 탐사 전용 | — | 가장 기본적인 탐사 자원. 미션마다 새로 받아 출발하고 남은 양은 사라집니다. 보급품이 없으면 보급품이 드는 선택지를 고를 수 없고 굶주림 피해를 받습니다([05 §1.1](05_exploration.md#11-탐사-진행-구조)). 이벤트의 식량·물·연료·자재와 '행동력 소모'는 모두 보급품으로 처리합니다. |
| 특정 병종 | 탐사 전용 | — | 원정대에 특정 병종이 있으면 그 병종을 선택지 비용으로 사용할 수 있습니다. |

> 이전 문서의 '드워프 유물'은 '명예'로 이름을 통일했습니다. 게임 데이터의 필드명은 `cost_honor`입니다.

## 6. 유닛 고용

| 항목 | 규칙 |
|---|---|
| 원정대 모병소 | 아이언풋 요새 내부에 있으며, 모집 가능한 유닛 리스트가 등장합니다. |
