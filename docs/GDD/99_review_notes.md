## 2. 정리 기록

### 2.1 바뀐 내용 (최신 기준으로 반영)

이전 문서(초안 CSV, PPTX)와 최신 문서(기획데이터 CSV)가 다른 경우 최신 문서를 따랐습니다.

| 항목 | 이전 (초안·PPTX) | 반영한 내용 (기획데이터) |
|---|---|---|
| 둠 페이즈 갱신 | 1주일 단위로 갱신 | 미션을 진행할 때마다 카운트 차감, 0이 되면 종료 |
| 둠 페이즈 갱신 단위 | 1주일 | 검토 결과 **둠 페이즈 1개 = 10일, 총 5페이즈(50일)로 확정** (2026-11-20, 게임 데이터의 10~50일차 표기와 같음) |
| 위협도와 대공세 | 위협도 100% → 버민킨 대공세 전투 | 기획데이터는 위협도 100% → 둠스데이 전투(엔딩). 검토 결과 **대공세는 페이즈마다 1개씩 강제 발생, 위협도는 대공세 강화에 사용, '둠스데이 전투' 개념은 제거**. 엔딩은 50일차 '왕의 관문' 결과로 결정 (2026-11-20) |
| 공세 대상 장소 | 브론즈가드 성채 | 검토 결과 **아이언풋 요새로 통일** (2026-11-20) |
| 전투 타입 | 일반 전투, 거점 공격, 거점 방어, 목표 제거 (4종) | 검토 결과 **게임 데이터의 미션 타입 6종(Defense, Extraction, Explore, Destroy, Detonation, Elimination)을 기준으로 확정, 이후 Capture 추가로 7종** (2026-11-20) |
| 난이도 단계 | 4단계 | 검토 결과 **4단계(매우 어려움 포함) 유지** (2026-11-20) |
| AP(행동력) | 유닛 설명에 AP 사용 | 검토 결과 **AP = MOV로 통일**, 문서의 전투 관련 AP 표현을 MOV로 변경 (2026-11-20) |
| 등급별 슬롯 | 1티어 특성1/스킬1, 2티어 특성2/스킬1, 3티어 특성2/스킬2 (초안) | 검토 결과 **게임 데이터 구조(특성 2, 패시브 4, 액티브 3)를 따르기로 함**, 이후 특성·패시브 통합으로 특성 6 / 액티브 3 (2026-11-20) |
| 대공세 패배 | 언급 없음 | 검토 결과 **대공세에서 패배하면 즉시 게임 오버** (2026-11-20) |
| 점령 타입 | 이전 '거점 공격' | 검토 결과 **Capture(점령) 타입을 7번째로 추가** (2026-11-20) |
| 탐사 비용 문구 | 행동력 소모, 시간 소요 (정의 없음) | 검토 결과 **행동력 소모 = 보급품 소모, 시간 소요 = 둠 카운트 추가 차감** (2026-11-20) |
| 소모품성 자원 | 식량, 물, 석탄, 연료, 자재 (정의 없음) | 검토 결과 **모두 보급품으로 통합** (2026-11-20) |
| 공포·사기 | 이벤트·스킬 문구에만 등장 | 검토 결과 **유닛별 공포 수치를 신설** (2026-11-20) |
| 슬롯 개방 | 정의 없음 | 검토 결과 **레벨이 오르면서 슬롯이 하나씩 열림** (2026-11-20) |
| 특성과 패시브 | 게임 데이터에 특성 2 + 패시브 4로 분리 | 검토 결과 **특성 6칸 하나로 통합** (2026-11-20) |
| 공포 불이익 | 정의 없음 | 검토 결과 **최대치에 이르면 패닉, 그 전에는 불이익 없음** (2026-11-20) |
| 공포 규칙 | 정의 없음 | 검토 결과 **범위 0~100, 100에서 1턴 동안 명령 거부(자동 행동) 후 공포 일부 감소. 전투 승리·서포터 스킬·특성·탐사 이벤트로 감소, 캠프 귀환 시 유지** (2026-11-20) |
| 패닉 행동 | 정의 없음 | 검토 결과 **도망·무작위 공격(아군 포함)·웅크림 중 무작위** (2026-11-20) |
| 이벤트 문구 처리 | 경험치, 아이템, 시야, 정신력 (정의 없음) | 검토 결과 **경험치 = 원정대 전원 XP, 아이템 = 캠프 창고, 시야 = 다음 전투 시야 버프, 정신력 = SP** (2026-11-20) |
| 미션 해결 효과 | 정해진 보상 획득 | 보상 획득 + 버민킨 공세 위협도 감소 |
| 대공세 미션 구성 | 미션은 탐사 + 전투 | 대공세 미션은 전투만 진행 |
| 고용 자원 | 골드, 드워프 유물 (2종, PPTX) | 골드, 명예, 무쇠 정수 (3종) |
| 희소 자원 이름 | 드워프 유물 (자원 목록), 명예 (인물 설정·이벤트) | 검토 결과 **같은 자원으로 보고 '명예'로 통일** (2026-11-20, 게임 데이터 `cost_honor`와 같음) |
| 탐사 자원 | 골드, 드워프 유물, 보급품, 특정 병종 | 무쇠 정수 추가, 드워프 유물 → 명예 |
| 이벤트 선택지 수 | 4개 (PPTX) | 2지 선다형과 4지 선다형 두 가지 |
| 선택지 비용 차감 | 언급 없음 | 즉시 차감, 1종류 이상의 자원 필요 가능 |
| 난이도 설명 | 저/중/고/최고 레벨 유닛 구성 | 레벨 범위 명시 (1~3 / 3~6 / 6~9 / 10) |
| 관통 | 관통 배율만 언급 | 기획데이터에서 'DEF 50% 무시'가 추가됐으나, 검토 결과 **관통 배율 방식으로 확정** (2026-11-20) |
| 명중 공식 | `(HIT / EVA x 1.5) × 100` (괄호 모호) | 검토 결과 **`HIT / (EVA × 1.5) × 100`으로 확정** (2026-11-20, 현재 코드와 같음) |
